# Thesis Review Workspace

The pilot gives students and their assigned supervisors a shared record of thesis chapter submissions, decisions, and revisions. A supervisor can request changes or mark a version reviewed so the student can continue.

## Try the prototype

[Open the clickable Figma prototype](https://www.figma.com/proto/vnzGM84esZHTiTaBjr2P58?node-id=2-2&starting-point-node-id=2%3A2) · [Open the editable Figma design](https://www.figma.com/design/vnzGM84esZHTiTaBjr2P58?node-id=2-2)

1. Open the student workspace, choose the sample PDF, and submit it. The confirmation identifies Version 1.
2. Open the supervisor queue, review Version 1, and choose **Request changes**.
3. Read the feedback, submit the sample revision, and open Version 2 in the supervisor view.
4. Choose **Mark reviewed**, then open chapter history to see both versions.
5. Restart to try direct approval of Version 1, missing-file recovery, or the GitHub progress update.

The clickable prototype uses preset files and feedback to demonstrate the flow. Workspace switching resets the demo to its entry screen. Real uploads, persistent state, sign-in, and access controls are implementation tasks.
